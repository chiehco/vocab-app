## 修正

- LV1 圖句卡與教材字卡：上一張／下一張固定在底部導覽上方，頁尾保留操作列的實際高度。左右滑一次切一張，首尾不循環，長卡仍可上下捲動。

## Chromium 手機驗證

只使用本任務開啟的 localhost 測試來源與非持久私密瀏覽器 context，未操作使用者手機或正式站學習資料。

- 原生 CDP 觸控事件：320×568、390×844、430×932；固定操作在導覽上方、首尾、連續左右滑、完成後返回、垂直捲動、音訊按鈕起手滑動通過。每次手勢完成後留待原生觸控序列結束再檢查後續操作。
- 作答首屏：320×568、360×740、390×844、430×932 的實測題目四個選項均在導覽列上方。極長詞義或放大字級仍允許自然捲動，沒有裁切選項文字。
- 揭答前後紀錄數、獎勵流水與錢包不變；明確保存只新增一筆；下一題不再保存、不改錢包，scrollY 為 0、說明折起、輪次計時起點不變。返回小鎮可續答。
- 小鎮全貌：320×568、360×740、390×844、430×932、844×390，LV1 38 個地塊無水平或垂直地圖溢位。最小直向房屋約 44.7px，橫向約 47.7px；放大工具與字卡操作至少 44px。LV4 與不同已建數量另有隔離 fixture 驗證。
- 安全區：CSS 使用 `env(safe-area-inset-bottom)`，操作列與底部導覽錯開。這版 Chromium 沒有 `Emulation.setSafeAreaInsets`；額外以 34px CSS 替代值量測，屬模擬，並非實體 iPhone／Safari 驗證。
