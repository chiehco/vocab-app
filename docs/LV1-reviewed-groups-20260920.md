# LV1 已核准 Unit 群組

使用者同意將已發布圖句按 Unit 做成 App 可選用的群組，保留既有自建群組。群組以 `lv1ReviewedImages.json` 為唯一來源，共 15 個模板。

- 入口：單字模式 → 加入 LV1 Unit 01–15 群組，或 `#/groups?create=1`。
- 可單獨加入／開啟，也可一次加入 15 個。啟動時不自動寫入使用者資料。
- 只納入已核准且有正式 ID 的字卡，單一 Unit 內去重（U02 movie／film 共用一張正式字卡，因此 37 張）。22 個補充詞保留對應 Unit 圖句入口，不虛構 ID／練習題。
- 一般字卡保留原有預設圖。同詞在別的 Unit 的確切圖句可從群組的「查看這個 Unit」連結查閱。
- 按 templateId 找已有群組，不以同名覆蓋；重複或跨分頁加入不會建立重複群組，也不覆寫使用者改名、刪詞或排序。
- 使用既有 wordIds 群組流程接單字模式、學習、一般練習與遊戲，沒有新增完整教材／文法課程。

驗收：52 個測試檔／252 項通過（本機限制 2 workers；初次高併發有兩個既有測試逾時，重跑全量通過）；新增群組檢查涵蓋 15 Unit、434 圖句、22 補充詞、正式 ID、去重、並行重複操作、保留既有同名群組與修改、未載入內容不得部分建立、其他進度表不變。修改檔 lint 0、build 0。

本機隔離瀏覽器一鍵加入 15 組、重按不新增、單字模式 U01 38 字、一般練習入口 38 字與 390px 無橫向溢出通過。圖片、母表、啟動包、SRS 計算與既有學習紀錄未修改。既有圖片驗收沿用 9f74ce0；完整 unitN.json 的 verify_unit.py 不適用本次純字卡群組模板，採群組模型與實際 UI 驗收。正式部署與版本紀錄見工作區 `work/LV1_圖片發布_20260920/群組發布紀錄.md`。實體手機未實測。
