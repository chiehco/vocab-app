### interact

ID：`CHOICE-CLOZE-ORIG-LV4U20-interact`

完整句：The children can interact with each other around the table.

挖空句：The children can _____ with each other around the table.

中文：孩子們可以在桌旁彼此互動。

既有答案：B · interact

| 選項 | 解析 |
|---|---|
| A · interactive | interactive（形容詞）是「互動的」，用來形容活動或設備。can 後這裡需要原形動詞，不能直接用這個形容詞表示孩子們的動作。 |
| B · interact（正解） | interact（動詞）是「互動、交流」。can 後接原形 interact；with each other 表示彼此，符合孩子們在桌旁互動的意思。 |
| C · disorder | disorder 常作名詞「混亂」，也可作動詞「使混亂」。本句要說孩子們彼此互動；can disorder with each other 不能表達這個意思，若用動詞 disorder，通常還要說明使什麼混亂。 |
| D · learned | learned 可以是 learn 的過去式或過去分詞「學習了」，也可作形容詞「博學的」。can 後要接原形動詞，不能用 learned；即使用 learn，也是在說學習，並不等同互動。 |

### interactive

既有答案：D · interactive

| 選項 | 解析 |
|---|---|
| A · disorder | disorder 可作名詞「混亂」或動詞「使混亂」。它不表示設備會回應使用者；本題後句說碰觸積木就會發光，並不是在描述混亂。 |
| B · learned | learned 可作形容詞「博學的」或「習得的」，也可作 learn 的過去式「學習了」。這些意思都不能說明積木受到碰觸便發光的互動功能。 |
| C · passive | passive（形容詞）可表示「被動的、不主動反應的」。passive blocks 在特定技術情境可以成立；但本題明說積木會回應孩子的碰觸而發光，interactive 更符合這項功能。 |
| D · interactive（正解） | interactive（形容詞）是「互動的、能與使用者互相回應的」。後句說孩子碰觸積木，積木就發光，直接說明這些積木具有互動功能。 |
