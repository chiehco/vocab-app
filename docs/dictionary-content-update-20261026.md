# 字典資料更新與重試

設定的「資料版本」區新增「更新字典資料」。它檢查已安裝範圍的內容，S+A 仍只下載啟動包，完整字庫才抓各表；不改學習進度、計分、母表或詞義。原「檢查網頁更新」繼續只處理程式／介面版本。

檢查期間停用按鈕並顯示進度；成功分為已更新／目前已最新，失敗明示保留舊資料且可在同頁重試。手動與背景更新共用進行中的工作，避免重複下載或互相覆蓋。只有成功取得並核對新回應才回報最新，離線失敗不作成功。

內容請求使用穩定的 `dictionary-update=1` 參數避開舊 service worker 的固定預快取，並以 HTTP `no-cache` 重新驗證，允許未變內容使用條件式回應。背景與手動採相同路徑，避免手動更新後又被舊快取覆蓋；每個下載有 30 秒上限。初次啟動與離線仍能直接使用既有內容。下載及筆數檢查完成後沿用原本單一 IndexedDB transaction 替換內容表，進度庫不參與。

本批以隔離合成資料驗證：S+A／完整字庫、新程式配舊 house、下載失敗後同頁重試、離線與恢復、重複操作、沒有新版本及錯誤提示。確認 house 兩義 approved 與三態後才比較 14 張非空進度表；不以尚未到齊的非同步等待當成功。實體手機及其他瀏覽器的結果以交付報告為準。本批只準備 draft PR，不含合併部署。
