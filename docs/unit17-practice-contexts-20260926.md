# Unit 17 多情境練習

使用者在「先發布兩項修正，再以 Unit 17 試做一個教學句＋兩個練習句」建議後指示「OK 依建議執行」。本次授權涵蓋此試行版的製作、接入與發布；不擴大到其他單元、母表或美術審核。

## 行為

- 作答前不顯示目標中文義；答後顯示完整句、翻譯、目標詞及解析。
- 教材／字卡的新練習使用完整範圍，每字一次，未練過／少練過者優先，同次數洗牌。
- LV4 Unit 17 的 46 詞保留原教學例句，另加每詞兩個練習情境，共 92 句。23 句沿用經本次義項檢查的既有 reviewed 例句，69 句本次撰寫。`practiceVariantsLV4Unit17.json` 逐句保存來源及原題對應。
- 新單元練習、群組練習、錯題重練均可選新情境；優先未作答情境，排除最近答過的同句。四選一的答案位置也隨情境改變。
- 換情境仍屬同一目標詞，涵蓋排序、錯題清單及畫面首答統計依目標詞彙整；選字與填字的成績獨立。新情境答對能解除該模式的舊情境錯題。
- `~P1`／`~P2` 是新增、不可覆寫的題目 ID。旧題、既有 session、attempt、revision 不變；同一 session 的題目保持固定。切換模式保留同一句並各自續答；匯出／匯入沿用既有備份格式。
- 其他單元的題目不套用 Unit 17 替換句；43 項用法仍沿用原題。課本／一般字卡的圖片和教學句、SRS、正式字庫與主 Excel 不變。

## 內容檢查

92 句已逐句核對單元指定義項、詞性、挖空位置、中文、選項語意與可接受答案。特別排除 elementary school、mild 天氣／病情、margin 分差、amateur 形容詞、glimpse 動詞等與本單元目標不合的既有候選。circular 與 oval 提供圓形／蛋形線索；frustrated／frustrating 區分人的感受與事物造成的感受；catalog／catalogue 填字均接受。
