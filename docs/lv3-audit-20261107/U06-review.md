## Donkey 歷史細節校正

正式字庫原英文把民主黨驢象徵記為 Nast 在1874年引入，與 [Smithsonian Libraries](https://www.sil.si.edu/ondisplay/caricatures/bio_nast.htm) 的 donkey 1870／elephant 1874 記載矛盾。[Ohio State 漫畫館藏](https://library.osu.edu/thomas-nast/a-live-jackass-kicking-a-dead-lion) 亦指出驢象徵早於 Nast。因此同一欄候選刪除錯誤的引入細節，保留民主黨象徵與動物義，不擴寫歷史故事。總數仍為144欄、56列，尚未套用。
