# 即時拼字守城

使用者完成數輪互動試玩後於 2026-09-22 明確指示「推吧」，授權本版接入與發布。

入口：遊戲 → 拼字守城（`#/arena/word-siege`）。先選課本等級及 Unit，再進入 60 秒守城。字盤自由依序點選，不要求相鄰；最後一個字母正確即出招。拼字及提示期間敵人持續移動，手動暫停與切到背景會暫停。

視覺延續核准試玩：上方草地戰場、下方字母盤，援軍留場射擊、冰凍改變敵人狀態、爆破清除前排。介面以戰場為主，Unit 設定獨立於遊玩流程。

## 內容與實作

- 援軍持續自動攻擊；冰凍全場減速 80% 共 8 秒；爆破攻擊最前方敵人周圍一群。城堡生命歸零即失敗，撐到 60 秒勝利。
- LV1 僅選既有已審閱群組的正式詞條，使用字典一般字義；不宣稱是圖句的唯一目標義項。未映射的補充詞不虛構 ID。
- LV3／LV4 使用既有單元 vocabulary 的 `displayWord`、`targetMeaningZh`。題庫不跨 Unit，洗牌後依序抽取；三種招式皆可搭配單元任一單字。
- 接受純 A–Z、2–16 字母；片語、符號及過長拼字不改寫。選單顯示實際可玩數，少於三詞不能開始。
- 每次切換招式／完成題目重建 25 格字盤，保證目前答案包含足夠的重複字母。長答案可換行。
- 遊戲由版本化 raw HTML 資源載入隔離 iframe，僅允許腳本；Unit 資料經 JSON 腳本跳脫注入。高度訊息只接受該 iframe 來源並限制範圍。無外部網路、無 Codex API。
- 保留原試玩的局內分數，離開頁面結束當局。沒有新增排名、學習進度、SRS、母表或教材內容修改。

## 驗證

- 55 個測試檔、264 項通過；lint、TypeScript、production build 通過。
- 題庫測試核對 LV4 Unit 20 每詞及詞義確實來自該 Unit，錯誤 Unit 不回退到其他單元；檢查不支援拼字、重複與腳本注入跳脫。
- 瀏覽器 LV1 Unit 01 顯示 38 詞，實際觸發三種技能，完整 60 秒結算成功，援軍 3、冰凍 1、爆破 1、擊退 37、2150 分。
- LV4 Unit 20 顯示 46 詞，驗證單元選擇、提示、暫停／繼續。不出招的完整實時回合確認城堡失守、0 分。320px 手機下父頁與遊戲無橫向溢出。實體手機未測。
- 加速時鐘對 sandbox iframe 的計時不可靠，因此勝負驗收使用真實時間，不以加速結果判定。
