# LV5 integration on the released LV4 baseline

This local integration retains released main `f057f0f419165e744ee590bcce02c5c2109e9bd4` and adds the eighteen source-accepted LV5 units from `580f8896c05a8ed3a4ea9c9bd0b2edd15fb23b1d`: U1, U3–U16, U18, U22 and U25. LV4 still exposes U1 and U3–U24. LV4 U2 remains hidden while its original 164 learning item identities and ordinary dictionary mappings remain available to saved groups and backups.

The curriculum registry keeps main's registrations and adds the accepted LV5 registrations. The starter pack is regenerated by the combined builder, rather than taking either parent's package. Its eight datasets are exact payload unions of the parents, with both parents' relative ordering preserved: 3,824 words, 768 senses, 5,949 examples, 19 relations, 3,021 morphemes, 2,743 notes, 2,680 exam priorities and 746 media rows. The new baseline fixture binds main's 3,094 word IDs, the held U2 learning item IDs and the accepted LV5 unit set for integration regressions. Existing dictionary examples and media are retained; this integration approves no new textbook examples or illustrations.

LV5 source/compiled JSON stays byte-identical to the accepted head. The ordinary noun `W005711` remains in the starter while LV5 U16's printed verb occurrence stays pending. LV5 U25's unsupported practice verb meaning also stays pending. No mother-table data, existing progress/SRS/reward code, package lock, PWA configuration or deployment workflow is changed by the integration.

LV4 U2 needs its complete p22 source. LV5 U2, U17, U19–U21 and U23–U24 are absent because their source photos remain incomplete or unreadable. No missing page has been inferred.

This branch is for local engineering, fresh-install and retained-PWA validation. Publishing, pushing, creating a PR, remote merging and deploying remain on hold pending explicit authorization. Local evidence and the final frozen SHA are delivered separately; this document does not assert that the branch is published.
